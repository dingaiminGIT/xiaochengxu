# 生成谷子前端

首页社区浮动入口 → `/pages/guzi/index`。旧万圣节页面保留以兼容历史链接，首页不再展示其任务弹窗。

## 已实现

- 单张 JPG/PNG 选择，10MB 校验、像素校验；取消选择保留原有输入。
- `/pages/guzi/crop` 提供 1:1 裁剪，拖动、双指缩放及滑杆缩放；Canvas 导出最大 2048px 正方形 JPEG，不放大低分辨率源图。更换/重新裁剪确认后才替换已选照片。
- 描述预填，右下角 Unicode 字符计数，上限 300；无辅助提示和恢复默认操作。
- 生成中的居中文案、原图遮罩与 1.8 秒循环扫光；禁止重复提交。
- 头像原图/58mm 圆形预览切换；保存的是原图；相册权限拒绝提供设置入口。
- 重新创作保留照片及描述；失败可重试；页面卸载取消本地演示任务。

## 服务接入边界

`pages/guzi/generation.js` 的 `createGeneration({ photoPath, prompt })` 是唯一生图适配位置，目前没有网络请求，2.4 秒后返回固定的演示猫头像。

契约：返回 `{ promise, cancel }`，promise 成功值为 `{ imagePath, isDemo }`。当前明确返回 `isDemo: true`，结果页显示“示例预览”，按钮为“保存示例原图”，不声称这是上传宠物的生成结果。真实接入时返回 `isDemo: false`。

接入时处理照片上传、创建任务、任务查询/取消、持久化恢复及下载域名配置；当前没有约定后端 URL、鉴权或响应结构，也不调用旧兑换码接口。后台轮询与跨页面/重启恢复尚未实现。本地演示在应用暂时切到后台时保留当前页面状态，退出本页则取消。

建议服务输出 `2048x2048`，单图；58mm 只为页面预览，不是印刷出血模板。300 字是产品上限，依据 Seedream 中文提示词长度建议，不等于模型接口硬上限。
