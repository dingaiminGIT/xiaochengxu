# 小佩设备连接知情同意书

文档版本：petkit-connect-2026-10-23-v1 · 待发布草案

## 拟发布正文

为在宠析中查看您在小佩 App 中已添加的设备及其记录，请在连接前阅读以下说明。本功能由宠析提供，不代表小佩对宠析的官方授权或背书。

**1. 您提交什么信息**

您需要主动输入小佩 App 的用户名和密码。宠析将通过加密传输接收这些信息，并由服务端向小佩服务发起本次身份验证。请仅连接您有权使用的账号。

**2. 我们不会保留您的用户名和密码**

用户名和密码仅用于本次身份验证，验证处理结束后不再保留，不写入宠析的小程序本地存储、数据库、文件、日志或备份。验证失败或连接失效时，您需要重新输入。我们不会将这些信息用于广告、营销或与设备连接无关的用途。

**3. 为何连接后仍能查询设备**

验证成功后，我们会在服务端加密保存小佩返回的必要登录会话凭证，用于后续查询设备。会话凭证具有访问权限，属于需要保护的信息；“不保留用户名和密码”不代表“不保存任何连接信息”。会话失效时，请重新连接，我们不会通过保存密码在后台重新登录。

**4. 我们读取哪些信息、用于什么目的**

连接成功后，为供您选择设备，我们会查询该账号可见设备的标识、名称、类型及支持能力。您确认绑定后，我们会按设备实际支持情况读取设备状态、同步时间、进食／出粮记录等，用于设备展示、记录查询及关联您选择的宠物。我们会保存必要的设备绑定关系和已同步记录；本次同意不包含远程出粮、修改设备配置或读取视频内容。

具体可用信息因型号和上游服务而异。设备数据可能属于多宠共用设备，不一定代表单只宠物的实际摄入量；连接成功也不代表已产生健康分析结论。

**5. 自愿选择与撤回**

您可拒绝连接，继续使用宠析的手动记录等其他功能。您可在“我的设备—小佩账号连接”中断开连接并撤回本功能同意。撤回后我们停止访问，删除该连接的会话凭证，并解除其有效设备绑定，不会删除您在小佩 App 内的设备。仅解绑某一台设备不会断开账号下其他设备。

断开连接时，您可选择同时删除宠析内已同步的设备历史数据；未选择时，历史数据仅供您继续查看，您也可随后申请删除。依法必须留存的最小信息将限制用途，并按正式隐私协议告知。手动记录和其他连接的数据不受影响。

**6. 进一步了解与联系**

请通过宠析《隐私协议》查看运营主体、个人信息权利及联系渠道。小佩服务对自身处理活动的说明见[《小佩宠物 App 隐私政策》](https://m.petkit.com/app/about/policy/cn.html)。本同意书说明的是宠析的处理活动，不能替代小佩政策，也不构成对设备接口持续可用的保证。

勾选“我已阅读并知情同意”并主动点击连接，表示您同意宠析按上述范围处理信息。您可以随时撤回。

## 实现约束（不放入面向用户的正文）

1. 默认不勾选；只限制此可选功能，不能以不同意为由阻止其他功能。打开全文不等于同意；重新认证再次主动勾选。
2. 服务端在发起小佩认证前验证 accepted 和当前 notice_version／privacy_version；同意记录保存宠析用户 ID、文档版本、服务端时间、撤回时间，不记录账号密码或完整认证请求。
3. HTTPS 传输；关闭认证路由的请求体记录、APM 内容捕获、错误上下文回传、分析埋点和表单回放。不得把凭据放入 URL、命令行参数、持久化队列、环境配置文件或备份。任务队列只携带认证后的 connection_id。
4. 本次认证中的内存使用不可避免；成功、失败、超时及取消后清除应用持有的凭据引用，不宣称能保证运行时物理内存即时擦除。前端离开／进入后台即清空密码，认证结果返回后清空两项输入。
5. 不能保存加密密码、用户名脱敏副本、可用于重新登录的密码散列来规避“不保存”承诺。会话字段采用白名单，剔除用户名和密码，只保留必要令牌及不可用于输入登录的服务端账号 ID；若库依赖保留账号密码才能工作，须改造后再上线，不能静默保留。
6. 会话加密、按用户连接隔离，仅限服务端使用；过期清理。断开连接删除会话，取消／阻断在途任务回写；上游支持撤销时同步撤销，不承诺当前未具备的上游注销能力。
7. 无设备或查询失败时仍可断开已建立连接；未完成绑定便退出流程的临时连接应删除，避免遗留有效会话。
8. 删除历史需覆盖数据库、快照导出、事件缓存及备份恢复策略；具体备份清除周期、同意记录留存期限须在正式协议中明确后发布。本草案不代表功能已实现。
